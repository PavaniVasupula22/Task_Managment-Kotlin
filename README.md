# Task_Managment-Kotlin

📌 Overview

This project is a Todo List Android application built using Jetpack Compose and Kotlin.
The application demonstrates how to build modern Android user interfaces using a declarative UI approach.

The app allows users to create, manage, and delete tasks in a simple and efficient way. It is designed as a learning project to understand how Jetpack Compose works for building Android UI components.

Jetpack Compose simplifies Android UI development by allowing developers to describe the UI using composable functions written in Kotlin.

🚀 Features

Add new tasks

View list of tasks

Delete tasks

Simple and clean UI

Built using Jetpack Compose components

Reactive UI updates when task data changes

🛠 Tech Stack

Language: Kotlin

UI Toolkit: Jetpack Compose

IDE: Android Studio

Build Tool: Gradle
